# Phase 06: 桌面增强与设置

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 托盘、全局唤起、单实例、窗口记忆、系统通知、亮暗主题与简单设置对话框。

**Architecture:** 全部用 Tauri 2 官方插件；主题用 CSS 变量 + `settings.theme`；通知挂在 git push/pull 与保存失败路径。

**Tech Stack:** window-state · notification · single-instance · global-shortcut · tray（Tauri 2 tray API / 插件）

## Global Constraints

见 [`00-落地总览.md`](./00-落地总览.md)。依赖阶段 05。
