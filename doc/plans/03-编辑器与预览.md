# Phase 03: 编辑器与预览

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 选中文件后可编辑、GFM 预览、800ms 防抖自动保存；Ctrl/Cmd+S 立即保存；切换文件先存后载。

**Architecture:** `editor` store 持有内容；`MarkdownEditor` 用原生 textarea；`MarkdownPreview` 用 `renderMarkdown` + `v-html`（DOMPurify）。

**Tech Stack:** marked · highlight.js · DOMPurify · Vitest（测 markdown/debounce）

**Interfaces:**

