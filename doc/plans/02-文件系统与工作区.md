# Phase 02: 文件系统与工作区

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户能打开本地目录，看到过滤后的文件树，完成新建/重命名/删除，并能读出 Markdown 文本（编辑 UI 在阶段 03）。

**Architecture:** 全部磁盘 IO 经 Rust `fs_ops`；前端 `workspace` store + `FileTree`/`TreeNode`；打开目录用 `dialog` 插件。

**Tech Stack:** walkdir · serde · Tauri dialog · Pinia

4. 启动时若有 `lastWorkspace` 则自动打开
