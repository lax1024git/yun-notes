### Task 2: 统一错误类型 `AppError`

**Files:**
- Create: `src-tauri/src/error.rs`
- Modify: `src-tauri/src/lib.rs`（`mod error;`）
- Test: `src-tauri/src/error.rs` 内 `#[cfg(test)]` 或 `src-tauri/src/error_tests`（单元测可与实现同文件）

**Interfaces:**
- Produces:

```rust
#[derive(Debug, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct AppError {
    pub code: String,
    pub message: String,
}

pub type AppResult<T> = Result<T, AppError>;

impl AppError {
    pub fn new(code: impl Into<String>, message: impl Into<String>) -> Self { /* ... */ }
}
```

- From `std::io::Error` → code `IO_ERROR`
- From `git2::Error` → code `GIT_ERROR`（可先写 From，crate 未加时用 feature 或稍后 Task 接 git2）
- `impl Serialize` 已满足；Tauri 需要 `impl From<AppError> for InvokeError` 或 `#[serde]` + `Result` 返回（Tauri 2 对 `Result<T, E: Serialize>` 支持）

- [ ] **Step 1: 写失败测试（错误码构造）**

```rust
#[test]
fn app_error_serializes_code_and_message() {
    let err = AppError::new("NOT_REPO", "not a git repository");
    let v = serde_json::to_value(&err).unwrap();
    assert_eq!(v["code"], "NOT_REPO");
    assert_eq!(v["message"], "not a git repository");
}
```

- [ ] **Step 2: 实现 `error.rs` 并使测试通过**

```bash
cd src-tauri && cargo test app_error_serializes -- --nocapture
```

Expected: PASS

- [ ] **Step 3: 注册空 commands 模块**
