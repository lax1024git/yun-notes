# 快捷工具箱

顶部工具栏点 **工具箱** 打开。四个模块在面板内切换，与工作区笔记、Git、启动锁都无关，处理结果默认留在面板里，需要时再复制或导出。

本次会话会记住上次打开的模块；切换页签不会清空已输入内容。点面板外、点关闭，或按 `Esc` 可收起。选择导出目录时面板不会被误关。

---

## 模块一览

| 编号 | 模块 | 做什么 |
|------|------|--------|
| 01 | 时间 | 时间戳 ↔ `YYYY-MM-DD HH:mm:ss`，带时区 |
| 02 | JSON | 校验、格式化、压缩、转义 / 去转义、Unicode ↔ 中文 |
| 03 | 图片 | 批量改格式、压缩质量、缩放，导出到本地目录 |
| 04 | 加解密 | AES / DES / MD5 / Base64 / Hash（通用文本工具，不是笔记加密） |

## 时间

打开时自动填入当前时刻。

1. 选 **时区**（列表含中国、UTC、纽约等；本机时区若不在列表里会单独出现）。
2. 选时间戳单位：**秒（10 位）** 或 **毫秒（13 位）**。
3. 在「时间戳」或「日期时间」里填一端，点对应按钮转换。

| 按钮 | 作用 |
|------|------|
| 时间戳 → 时间 | 按当前时区写成 `YYYY-MM-DD HH:mm:ss` |
| 时间 → 时间戳 | 把日期时间按当前时区解析成时间戳 |
| 现在 | 填入当前时间戳和对应日期时间 |
| 复制 | 复制该输入框内容 |

改单位会按同一时刻重写时间戳数字；改时区会按同一时间戳重写日期时间。日期时间格式为 `YYYY-MM-DD HH:mm:ss`（中间也可以用空格或 `T`）。

## JSON

把文本贴进编辑区，再点操作。支持带 `//`、`/* */` 注释以及对象 / 数组末尾多余逗号的 JSONC。

| 按钮 | 作用 |
|------|------|
| 校验 / 格式化 | 解析后按 2 空格缩进重写 |
| 压缩 | 去掉空白，输出一行 |
| 转义 | 整段变成 JSON 字符串字面量（带引号和 `\n` 等） |
| 去转义 | 把转义后的字符串还原成原文 |
| Unicode 转中文 | 把 `\uXXXX` 解成汉字 |
| 中文转 Unicode | 非 ASCII 写成 `\uXXXX`，ASCII 原样保留 |
| 复制 | 复制当前编辑区 |
| 清空 | 清空编辑区 |

格式化 / 压缩会先去掉注释再解析。若整段是「外面再套一层引号的 JSON 字符串」，也会尝试拆开再解析。

## 图片

1. 点击虚线框或把图片拖进去（可多张）。支持常见浏览器能解码的格式（JPG / PNG / WebP / GIF / BMP 等）。
2. 设好输出参数。
3. 点 **批量转换**，选一个导出目录；每张写出同名、换扩展名的新文件。

| 选项 | 说明 |
|------|------|
| 输出格式 | JPEG / PNG / WebP |
| 压缩质量 | JPEG、WebP 有效（约 10%–100%）；PNG 忽略 |
| 保持原尺寸 | 不改宽高 |
| 限制最大宽高 | 不超过填写的宽 / 高（可只填一边） |
| 指定宽高 | 拉到目标尺寸；勾选「保持宽高比」则适应框内、不拉伸 |
| 按比例缩放 | 5%–200% |

转换过程中会显示进度。列表里可单独移除某张，或清空列表。成功项会显示输出像素和体积。

## 加解密

左侧明文，右侧密文 / 摘要，中间选算法和密钥。

**这是文本小工具，和各工作区的笔记加密密码、磁盘 `NW1` 密文不是同一套。** 这里加密的结果不能用来解锁笔记。

| 模式 | 加密 → | ← 解密 | 密钥 |
|------|--------|---------|------|
| AES加密/解密 | AES-256-GCM，输出 Base64（含随机 IV） | 需要同一密钥 | 可选，可留空 |
| DES加密/解密 | DES-ECB + PKCS#7，输出 Base64 | 需要同一密钥 | 可选，可留空 |
| MD5 | 生成 32 位十六进制摘要 | 不可逆 | 无 |
| Base64加/解密 | UTF-8 文本编码 | 解码回文本 | 无 |
| Hash | SHA-1 / SHA-256 / SHA-512 十六进制摘要 | 不可逆 | 无 |

其它按钮：

- **交换**：左右文本对调
- **清空**：清空两侧（不清密钥）
- **复制**：复制该侧文本

AES 用 PBKDF2 从密码派生密钥（固定盐、10 万次迭代）；同一明文同一密码每次密文仍会不同（IV 随机）。DES 仅作兼容旧系统的便捷工具，不适合保护敏感数据。

## 注意

- 工具箱数据只在当前面板，关软件即丢失（图片导出到磁盘的文件除外）。
- JSON、加解密都在本地完成，不会上传。
- 笔记读写请用工作区加密，不要用工具箱 AES/DES 代替。
