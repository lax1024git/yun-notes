# Lax1024 Tools 使用文档

> 本地 Markdown 笔记工作台：磁盘密文存储、多工作区 Tab、Git 同步、实用工具箱。  
> 版本：0.1.0

---

## 1. 产品简介

**Lax1024 Tools** 是一款桌面端笔记工具，主要能力：

| 能力 | 说明 |
|------|------|
| 加密笔记 | 笔记以密文保存在本地；打开/编辑时自动解密 |
| 多工作区 | 顶部浏览器式 Tab，每个 Tab 对应一个本地目录与独立 Git / 加密配置 |
| Git 同步 | 本地提交、推送、拉取（仓库中始终是密文） |
| 工具箱 | 时间转换、JSON、图片格式、常用加解密小工具 |

**不会**把明文笔记上传到云端；Git 远程上看到的也是加密后的文件。

---

## 2. 安装与启动

### 开发模式（本仓库）

```bash
pnpm install
pnpm tauri dev
```

### 日常使用

安装或运行打包后的桌面程序即可。配置保存在本机应用数据目录（Windows 示例：`%APPDATA%\com.laxtools.desktop\settings.json`）。

---

## 3. 启动密码锁

可在 **设置 → 启动密码锁** 中启用。

- 仅用于**进入应用**，与笔记文件加密**无关**。
- 启用后，每次打开软件需输入启动密码。
- 忘记启动密码：需手动清理配置中的锁相关字段（或重装后丢失配置），无法从软件内找回。

> 请勿把启动密码当作工作区笔记加密密码混用；两者可以相同，但存储与校验是分开的。

---

## 4. 工作区 Tab

顶部 Tab 栏类似浏览器：

| 操作 | 说明 |
|------|------|
| **+** | 新建空白 Tab，再选择本地目录绑定 |
| 点击 Tab | 切换工作区 |
| Tab 右侧 **···** | 打开「工作区设置」 |
| 关闭 Tab | 移除该工作区入口（不删除磁盘上的文件） |

### 会自动保存的信息

切换、重命名、改路径、改远程、设置加密后，会写入本地配置，**下次打开软件会自动恢复 Tab 列表与上次激活的工作区**。

每个 Tab 大致保存：

- 显示名称、本地路径  
- Git 远程地址（可含 Token）  
- 该工作区加密密码的校验信息（盐与哈希，**不含明文密码**）

进程内记住的加密密码**不会**写入磁盘；重启后需再次输入该工作区的加密密码。

---

## 5. 工作区加密密码（重要）

每个 Tab 可设置**独立的笔记加密密码**。

### 何时需要设置 / 解锁

- 打开尚未配置加密的工作区 → 弹出「设置工作区加密密码」  
- 已配置但本次进程未解锁 → 弹出「解锁工作区加密」  
- 也可在 **工作区设置 → 笔记加密密码** 中修改  

弹窗可用右上角 **×**、底部「关闭」或点击遮罩关闭。

### 设置时注意

| 字段 | 说明 |
|------|------|
| 原加密密码 | 目录里**已有加密笔记**时必填（当初加密用的密码）；全新空目录可留空 |
| 新加密密码 | 至少 4 个字符；将用于之后加解密本工作区笔记 |

- **启动锁密码 ≠ 笔记加密密码**。例如启动锁是 `lax2dsqQ`，并不代表该工作区笔记也是这个密码。  
- 忘记工作区加密密码后，**无法解密已有密文**，软件无法找回。请自行妥善保管。  

### 磁盘上的表现

- 工作区根目录会有 `.nw-crypto.json`（密钥派生用盐，不含密码）  
- 笔记文件头为 `NW1` 格式密文  
- 非笔记文件（如 `.pem`、图片等）一般原样存放，导出时也会原样复制

## 6. 文件树与笔记编辑

### 文件树

- 左侧展示当前工作区目录  
- 点击笔记打开编辑  
- **右键**菜单：

| 菜单项 | 说明 |
|--------|------|
| 新建文件 / 新建目录 | 在当前右键所在目录创建 |
| 导出解密工作区 / 文件夹 / 文件 | 解密后导出到所选目录（需已解锁加密） |
| 重命名 / 删除 | 对非根路径可用 |

支持拖拽移动文件/文件夹。

### 编辑器

工具栏可切换：

- **编辑**：仅编辑区  
- **分栏**：编辑 + 预览  
- **预览**：仅预览  

未保存时路径旁有 ● 标记；支持保存（工具栏或关闭窗口时尽量自动保存）。

---

## 7. 导出解密文件

两种入口：

1. **工具栏 / 设置**：「导出明文」→ 导出**整个当前工作区**  
2. **文件树右键**：「导出解密…」→ 可导出整库、某一文件夹或单个文件  

要求：

- 当前工作区加密已解锁  
- 导出目录**不能**选在工作区内部  

导出结果为明文 Markdown/文本（及其他非笔记文件的副本），便于备份或对外分享。

## 8. Git 同步

侧边 Git 面板：

1. 在**工作区设置**中填写完整远程地址并「设为当前 origin」  
2. 填写提交说明 → **提交**  
3. **推送** / **拉取**

### 远程地址示例

**GitHub（推荐）：**

```text
https://x-access-token:<TOKEN>@github.com/<owner>/<repo>.git
```

**Gitee：**

```text
https://oauth2:<TOKEN>@gitee.com/<owner>/<repo>.git
```

也可先填不含 Token 的 HTTPS 地址，再依赖应用内保存的 Token 注入（请勿使用易出错的 `https://TOKEN@github.com/...` 裸格式）。

### 注意

- Git 推送/拉取的是**磁盘上的密文**，协作方需使用本软件并知道对应工作区加密密码才能阅读。  
- Token 属于敏感信息，勿提交到公开仓库或发到聊天记录；泄漏请立即到平台作废并换新。  
- 若推送走系统代理失败，请检查本机代理/网络设置。

## 12. 推荐日常流程

1. 打开软件 →（如有）输入**启动密码**进入  
2. 选择或新建工作区 Tab → 绑定本地目录  
3. 首次使用：设置该工作区的**笔记加密密码**并牢记  
4. 之后每次打开该 Tab：输入该工作区加密密码解锁  
5. 编辑笔记 → 保存（磁盘自动为密文）  
6. 需要同步：配置远程 → 提交 → 推送 / 拉取  
7. 需要明文备份：右键或设置中「导出解密」

## 13. 常见问题

### 为什么启动密码能进软件，但打不开笔记？

启动锁与工作区加密是两套密码。请在解锁弹窗中输入**该工作区的加密密码**，不是启动锁。

### 提示「加密密码错误」或解密失败？

- 确认是否记错了**工作区**密码（不是启动锁）  
- 换过密码后，旧密码无法打开已按新密码重加密的笔记  
- 从别处拷来的密文，必须使用**当初加密时**的密码  

### 关闭加密弹窗后无法读写笔记？

关闭仅表示暂不解锁。可再次切换 Tab 或重新打开该工作区，再次弹出解锁/设置对话框。

### Tab 下次打开还在吗？

会。名称、路径、远程、加密校验信息会持久化；明文加密密码不会持久化。

### 能否只用一个密码管所有工作区？

可以人为设成相同字符串，但每个 Tab 仍各自保存校验信息；切换 Tab 时若密码不同需分别解锁（相同则会在本次进程中缓存）。

### 忘记工作区加密密码怎么办？

无法从软件恢复。只能：

- 若有明文导出备份，重新导入到新工作区并设置新密码；或  
- 放弃该目录下已有密文笔记。

---

## 14. 安全建议

1. 为重要工作区使用足够长的独立加密密码，并离线备份密码。  
2. 定期「导出解密」到安全位置做明文备份（注意备份介质权限）。  
3. Git Token 用后及时在平台权限最小化；勿把带 Token 的 URL 发到公开处。  
4. 不要把启动锁密码和所有工作区加密密码全部设成同一个弱口令后到处泄露。

## 15. 技术摘要（可选阅读）

| 项目 | 说明 |
|------|------|
| 笔记密文 | `NW1` + AES-256-GCM |
| 密钥派生 | Argon2id（密码 + 工作区 `.nw-crypto.json` 中的盐） |
| 密码校验 | SHA-256（盐 ‖ 密码），存于 Tab 配置，不存明文 |
| 技术栈 | Tauri 2 + Vue 3 |
